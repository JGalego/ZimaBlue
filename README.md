🌊 **ZimaBlue — simulate, test, and replay robotic pool cleaners.**

ZimaBlue is a robotics testbed for swimming-pool cleaning robots: a pool, a
cleaner, dirt, imperfect sensors and control software go in — a recorded,
replayable, measurable cleaning run comes out.

> **Status:** early development. The fast 2D backend is the working
> implementation; the 3D backend is an interface plus a design document.

## Quick start

```bash
pip install -e .
zimablue demo
```

See `docs/` for architecture and research notes.
